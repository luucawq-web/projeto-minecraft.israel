Bem-vindo!

Minecraft é um jogo de aventura, construção e sobrevivência desenvolvido pela Mojang Studios.

No jogo, o jogador pode explorar um mundo formado por blocos, coletar recursos, construir estruturas, enfrentar criaturas e descobrir diferentes lugares.

Sobre este projeto

Este site foi criado para apresentar algumas das principais características do Minecraft utilizando somente HTML.
