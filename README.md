# projeto-minecraft.israel

## Sobre

Este projeto foi desenvolvido como uma atividade acadêmica sobre o jogo Minecraft.

O site apresenta informações sobre a história, modos de jogo, mobs, bosses, biomas, itens, encantamentos e dimensões.

## Tecnologias

- HTML5
- Visual Studio Code
- GitHub

## Ferramentas utilizadas

Para desenvolver o projeto, utilizei:

- ChatGPT para ajudar com dúvidas e organização do código.
- YouTube para pesquisas e aprendizado.
- Aulas do professor Israel da Costa como base para aprender HTML.
