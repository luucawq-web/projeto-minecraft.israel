Sobre mim

Meu nome é Lucas Gabriel Vieira da Silva e este projeto foi desenvolvido como uma atividade acadêmica.

Sobre o projeto

Neste projeto bem simples desenvolvi um site sobre o jogo Minecraft, apresentando informações sobre sua história, modos de jogo, mobs, bosses, biomas, itens, encantamentos e dimensões.

O objetivo foi colocar em prática os conhecimentos aprendidos durante as aulas de desenvolvimento web, utilizando HTML para criar as páginas e organizar as informações.

O que eu fiz no projeto

  • Criei as páginas do site.
  • Organizei os conteúdos sobre Minecraft.
  • Criei os menus para navegar entre as páginas.
  • Utilizei títulos, textos, listas e tabelas em HTML.
  • Organizei os arquivos do projeto.
  • Testei os links entre as páginas.

Ferramentas que me ajudaram

Durante a realização do projeto, utilizei algumas ferramentas e fontes de aprendizado para conseguir desenvolver o site.

  • ChatGPT: ajudou com explicações, ideias, organização do código e dúvidas durante o desenvolvimento.
  • YouTube: utilizado para assistir vídeos e aprender sobre HTML e desenvolvimento de páginas.
  • Aulas do professor Israel da Costa: foram importantes para aprender os conceitos de HTML e colocar os conhecimentos em prática no projeto.
  • Visual Studio Code: utilizado para escrever, organizar e testar os códigos HTML.

Conclusão

A realização deste projeto foi uma forma de colocar em prática o que aprendi nas aulas. Durante o desenvolvimento, também pude pesquisar, testar códigos e aprender novas formas de organizar uma página web.
